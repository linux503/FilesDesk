# Changelog

## 1.1.2 — 2026-08-14

- New rule: drop the first N characters from a name

## 1.1.1 — 2026-08-14

- Live preview updates as soon as you type a rule
- Refresh button reloads names, permissions, and missing files from disk
- Numbering counts only files or folders in the current scope
- More built-in presets: videos, WeChat photos, copy numbers, dates, sequential names

## 1.1.0 — 2026-08-14

- Chinese-first UI, with files and folders in the same rename list
- Nested folders can be renamed together (prefix no longer blocked as an error)
- Smart suggestions for camera names, screenshots, Finder copy numbers, and folder prefixes
- Redesigned in-app sidebar and website navigation
- Universal binary for Apple silicon and Intel

## 1.0.0 — 2026-08-14

- Native macOS 14+ batch rename app
- Live preview for combined rules
- Validation that blocks overwrite, duplicates, empty names, and permission errors
- Two-phase rename with undo and history
- Presets stored in SwiftData
- Sparkle update feed on the FilesDesk website
