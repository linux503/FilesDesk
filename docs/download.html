Download

FilesDesk is a native Mac app for macOS 14 Sonoma and later. The current release is 1.0.0.

Download .zip Source on GitHub

After install

Open the zip, move FilesDesk to Applications, then add files or a folder. The app checks for updates from this site through Sparkle.

Requirements

  • Apple silicon or Intel Mac
  • macOS 14 or later
  • Permission to rename files you select
