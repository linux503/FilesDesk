FAQ

Does preview rename files?
No. Preview only computes new names in memory. Disk writes start after validation, when you click Rename.
Can FilesDesk overwrite a file?
No. If a target name already exists, or two files would share a name, rename is blocked.
How does undo work?
Each successful batch is stored in History with the old and new paths. Undo restores the original names using the same two-phase rename.
What are presets?
A preset is a saved set of rules. Photography, Screenshots, E-commerce, and Documents ship built-in. You can save your own.
How do in-app updates work?
FilesDesk uses Sparkle. The app reads an update feed on this site and installs a signed build from GitHub Releases.
Is there an account?
No. There is no login, cloud sync, or telemetry account.
