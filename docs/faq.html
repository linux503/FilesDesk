常见问题

预览会改文件吗？
不会。预览只在内存中计算新文件名，只有点击「重命名」并通过校验后才会写入磁盘。
会覆盖已有文件吗？
不会。若目标名已存在，或批量结果出现重名，重命名会被阻止。
撤销怎么用？
每次成功重命名都会写入历史，记录原路径与新路径。可从完成提示或历史页撤销，恢复原名。
预设是什么？
预设是一组可复用的规则模板。内置摄影、截图、电商、文档等模板，也可保存自己的规则。
如何在线更新？
应用使用 Sparkle，读取本站 appcast.xml，并从 GitHub Releases 下载已签名的更新包。
需要账号吗？
不需要。无登录、无云同步、无账号体系。
