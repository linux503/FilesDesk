核心能力

看得见，改得准，丢不了

从导入到执行，每一步都先预览、再校验、最后才写入磁盘。

01

实时预览

规则一边输入，新名称一边更新。预览不写磁盘，不必点生成。

02

智能建议

识别相机文件、截图、拷贝编号和所在文件夹，一键套用规则。

03

安全校验

重名、覆盖、空名、非法字符、无权限——有错误就阻止执行。

工作流程

三步完成批量重命名

1

添加

拖拽文件或文件夹。可只重命名文件夹，或导入其中的内容。

2

配置规则

添加规则或套用建议，列表马上显示新名称。⌘R 可刷新磁盘上的最新状态。

3

安全执行

校验通过后一键重命名。两阶段临时名处理，支持 A↔B 互换。

更多特性

专业工具该有的细节

灵活导入
拖拽、添加文件、添加文件夹。列表显示原名、新名、类型、大小、状态。支持搜索、全选、快速查看、在 Finder 中显示。
文件与文件夹
可只重命名文件夹，或只重命名其中的文件。编号只对当前范围连续计数。底部范围：全部 / 文件 / 文件夹。
智能建议
根据文件名给出摄影、截图、拷贝编号、文件夹前缀等建议，点一下即可套用。
刷新状态
⌘R 从磁盘重新读取名称、权限。已删除的项目会从列表去掉，再立刻更新预览。
预设模板
12 套内置：摄影、截图、电商、文档、视频、微信图片、去掉拷贝编号、日期前缀、顺序编号等。也可保存自己的规则。
大规模处理
支持 10,000+ 文件。预览在后台线程计算，不阻塞界面。
原生 macOS
SwiftUI + AppKit。浅色/深色自动适配。Universal：Apple 芯片与 Intel。
自动更新
Sparkle 应用内更新，EdDSA 签名验证。
安全机制

绝不丢失用户文件

重命名前全面校验，执行时使用临时名避免冲突，中断后可恢复。

  • 禁止覆盖已有文件
  • 检测批量重名冲突
  • 拦截空文件名与非法字符
  • 检查目录写入权限
  • 两阶段临时重命名
  • 中断后自动恢复
