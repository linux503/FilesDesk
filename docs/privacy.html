隐私政策

FilesDesk 是本地工具，不创建账号，不上传你的文件。

文件名、路径、预设与重命名历史保存在你的 Mac 上（应用沙盒内）。仅对你主动添加的文件进行读取与重命名。

若开启自动更新，Sparkle 会定期请求本站的公开更新源，并可能从 GitHub Releases 下载已签名的安装包。请求包含应用版本等常规 HTTP 信息。可在「设置」中关闭自动检查。

本站为静态页面，不使用追踪 Cookie，也不接入第三方统计。

如有问题，请在 GitHub 提交 Issue。 GitHub
