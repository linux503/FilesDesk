Privacy

FilesDesk is a local utility. It does not create an account, and it does not upload your files.

File names, paths, presets, and rename history stay on your Mac, in the app sandbox. FilesDesk only reads and renames items you add yourself.

If automatic updates are on, Sparkle periodically requests the public update feed at this website and may download a signed app archive from GitHub Releases. That request includes standard HTTP metadata such as your app version. You can turn automatic checking off in Settings.

This site is static. It does not set tracking cookies or run an analytics account.

Questions: open an issue on GitHub.
